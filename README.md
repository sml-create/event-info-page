# オンラインイベント案内ページ

`index.html` だけで表示できる、日本語のサンプルイベント案内ページです。デザインとイベント情報がすべてこのファイル内に入っています。インターネット接続、Python、サーバーの起動、JavaScriptは不要です。

## ダウンロードして確認する

1. GitHubの作業用ブランチを開きます： https://github.com/sml-create/event-info-page/tree/event-page-draft
2. 緑色の「Code」ボタン →「Download ZIP」をクリックします。
3. ダウンロードしたZIPを展開します。Windowsでは右クリック →「すべて展開」、MacではZIPをダブルクリックします。
4. 展開したフォルダ内の **`index.html` をダブルクリック** します。ブラウザでイベント情報がすべて表示されます。

前のバージョンと混同しないよう、新しく展開したフォルダのファイルを開いてください。ZIPの中から直接開かず、先に展開してください。ファイルの拡張子が非表示の場合は「index」と表示されることがあります。

GitHubで `index.html` をクリックすると、通常はソースコードが表示されます。デザインを見るときはダウンロードしたファイルを開いてください。

## 文章を修正する（PC）

1. 念のため `index.html` をコピーしてバックアップします。
2. `index.html` をテキストエディターで開きます。Windowsなら右クリック →「プログラムから開く」→「メモ帳」を選びます。Macのテキストエディットは、設定の「開く／保存」で「HTMLファイルを、フォーマットされたテキストではなくHTMLコードとして表示」を有効にしてから開いてください。
3. `Ctrl+F`（Macは `Command+F`）で、変更したい現在の文章を検索します。例：`2026年11月18日（水）`、`山田 花子`。
4. 日本語の文章部分だけを書き換えます。`<h1>`、`</h1>` などの `< >` で囲まれた記号は残してください。編集箇所には日本語のコメントも付けています。
5. **UTF-8のテキストとして保存**し、ファイル名を `index.html` のままにします。`index.html.txt` や `.rtf` にしないでください。
6. ブラウザで開いているページを再読み込みして確認します。

タイトル・日時・参加費・企業名は複数箇所にあります。「すべて検索」して、見つかったすべての箇所を修正してください。ブラウザのタブに表示される名前は `<title>` 内にあります。

例：

```html
<h3 id="speaker-name">山田 花子</h3>
```

この場合、`山田 花子` の部分だけを変更します。文章中で `&` は `&amp;`、`<` は `&lt;`、`>` は `&gt;` と書きます。

現在はサンプルのため申し込みを受け付けていません。受付を開始する際は、HTML内の次の段落を探します。

```html
<p id="application-unavailable" class="demo-status">サンプルのため、お申し込みは受け付けていません</p>
```

これを次のようなリンクに置き換え、`https://example.com/register` を実際の申込フォームのURLに変更します。

```html
<a class="button" href="https://example.com/register">参加を申し込む ↗</a>
```

このページ自体には申込フォームやメール送信機能はありません。既存の申込ページ等のURLを設定してください。問い合わせ先は「サンプルページのため、お問い合わせ窓口は未設定です。」という文章を実際の連絡先に置き換えます。実イベントの案内にするときは、ページ上部とフッターのサンプル表記も修正してください。

## 修正をGitHubの作業用ブランチに保存する

1. 上記の `event-page-draft` ブランチの画面に戻ります。
2. 「Add file」→「Upload files」をクリックします。
3. 修正した `index.html` をアップロードします。
4. 画面下の保存先が `event-page-draft` であることを確認し、「Commit changes」をクリックします。

GitHub上で文章だけ修正する場合は、`event-page-draft` の `index.html` を開き、鉛筆アイコンから編集して「Commit changes」で保存する方法もあります。保存後は新しいZIPをダウンロードして表示を確認します。

**まだWebページの一般公開はしていません。** 今回は `main` への統合や「Settings → Pages」の設定は不要です。PCでファイルを開いても、Webサイトとして一般公開されることはありません。GitHub上のファイル自体の閲覧範囲は、リポジトリの公開・非公開設定に従います。

## ファイル構成

- `index.html`：イベント情報とデザインを含む、単独で表示できるファイル
- `README.md`：この操作説明

以前の `event.json`・`app.js`・`style.css` は不要になりました。古いフォルダに残っていても読み込みませんが、最新版を新しいフォルダに展開する方法がおすすめです。

## 確認した内容

Chromiumで375・390・768・1440px幅でのレイアウト、プログラム3件、注意事項5件、ページ内リンクを確認しました。JavaScript無効・オフラインのブラウザにHTMLを直接渡した状態でも、全情報が表示されることを確認しました。外部ファイルへの参照はありません。この開発環境は管理ポリシーで file:// の表示が禁止されているため、ダブルクリック操作そのものは未検証です。公開サイトでの検証は行っていません。
