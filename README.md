# 白紙からつくるWebページ

決まった項目やサンプル文章のない、自由編集用ツールです。背景は白、文字は黒が基本で、スマートフォン対応です。ログイン・データベース・サーバー起動は不要です。

- `index.html`：公開用ページ。現在は完全な白紙です。
- `editor.html`：文章を作成する編集専用ツール。最初は白紙です。

## ダウンロードして始める

1. https://github.com/sml-create/event-info-page/tree/event-page-draft を開きます。
2. 緑色の「Code」→「Download ZIP」をクリックします。
3. ZIPを展開します。Windowsは右クリック→「すべて展開」、Macはダブルクリックします。
4. 新しく展開したフォルダの **`editor.html` をダブルクリック**します。

過去に保存した編集用ファイルには以前の文章が残っています。完全な白紙から始めるときは、今回ダウンロードした新しいファイルを使用してください。

## 文章を自由に作成する

1. 「追加する種類」で「大見出し」「中見出し」「小見出し」「本文」を選びます。
2. 「文章を追加」を押し、白いページの枠内に入力します。
3. 次の文章は、選択中の文章の直後に追加されます。既存の文章の間に追加したい場合は、その直前の文章をクリックしてから追加してください。
4. 編集したい文章をクリックして書き換えます。Enterで改行できます。
5. 文字をドラッグして選択し、「太字」や「リンク設定」を押すと装飾できます。リンク先は `https://`、`http://`、`mailto:`、`#` から始まるものを指定します。「リンク解除」で通常の文章に戻せます。
6. 本文内をクリックして「箇条書き」を押すとリストを入力できます。Enterで次の項目へ、空の項目でもう一度Enterを押すとリストを終了できます。
7. 対象の文章をクリックして「上へ」「下へ」で並べ替え、「選択した文章を削除」でその文章全体を削除できます。

好きな位置とは、文章の前後の順序を自由に決められる方式です。画面の任意の座標に文字を置く方式ではないため、スマートフォンでも読みやすく表示できます。

文章入力の取り消しは `Ctrl+Z`（Macは `Command+Z`）が使えますが、文章全体の削除や並べ替えの取り消しは保証しません。大きな変更の前は編集用コピーを保存してください。

## 見た目を確認する

「プレビュー」で編集用の枠線と入力ヒントを消し、公開ページと同じ見た目を確認します。「編集」で作業に戻ります。

「表示幅」→「スマートフォン」で390px幅のプレビューになります。実際の端末とは文字の表示が異なる場合があるため、公開後は実機でも確認してください。

「ブラウザのタブ名」は公開ページのタブに表示する名前です。ページ本文には表示されません。

## 保存する（2種類あります）

### 次回も編集したいとき：編集用コピーを保存

「編集用コピーを保存」を押すと、文章を含む新しい `editor.html` をダウンロードできます。次回はその保存したファイルを開いてください。別のPCに渡す場合もこのファイルを渡します。

**自動保存・PC間の自動同期はありません。終了する前に必ず保存し、ダウンロード先にファイルがあることを確認してください。** 同名ファイルは `editor (1).html` のようになることがあります。最新のファイルを区別して保管してください。

### Webで公開したいとき：公開用HTMLをダウンロード

「公開用HTMLをダウンロード」で、完成した `index.html` を保存できます。編集ボタンや編集用スクリプトは含まれず、このファイルだけで表示できます。サーバーの起動や外部データの読み込みは不要です。

同名ファイルがある場合は `index (1).html` などになるため、GitHubへアップロードするときは **`index.html`** に変更してください。

公開用HTMLだけでは編集ツールの作業状態は保存されません。必ず編集用コピーも保存してください。ダウンロードだけでWebサイトが更新されることはありません。

## GitHub Pagesで公開する（公開すると決めたときだけ）

GitHub Freeでは通常、公開リポジトリでPagesを無料利用できます。非公開リポジトリは契約・組織設定によって条件が異なります。リポジトリを公開にする前にソースを公開してよいか確認してください。

1. 完成した公開用 `index.html` をダウンロードします。
2. GitHubで作業用ブランチ `event-page-draft` を開き、「Add file」→「Upload files」からその `index.html` をアップロードし、「Commit changes」で保存します。
3. ダウンロードして見た目とリンクを確認します。
4. https://github.com/sml-create/event-info-page/compare/main...event-page-draft を開き、「Create pull request」で変更の取り込み依頼を作成します。
5. 公開の準備ができたら「Merge pull request」→「Confirm merge」で `main` へ反映します。権限や保護ルールによっては管理者の操作が必要です。
6. 「Settings」→「Pages」を開きます。
7. 「Source」で「Deploy from a branch」を選び、ブランチを `main`、フォルダを `/ (root)` にして「Save」を押します。
8. 数分待ち、Pages画面の「Visit site」または表示された公開URLで内容を確認します。反映状況は「Actions」のPagesデプロイ結果で確認できます。
9. その公開URLをメルマガへ掲載します。

想定URLは `https://sml-create.github.io/event-info-page/` ですが、未公開・未検証です。Pages画面の実際のURLを使用してください。Pagesが既に有効な場合、公開元の `main` に反映した時点で更新が公開されます。

公開後の修正も、最新の編集用コピーで編集→公開用HTMLをダウンロード→GitHubの公開元へ反映する流れです。

通常の公開ページには編集ボタンはありません。Pagesは公開元にあるファイルを配信するため、編集ツール自体をWeb上に置きたくない場合は、公開元の `main` から `editor.html` を除き、編集用ファイルはPCに保管してください。ツールにアクセスできても、GitHubの書き込み権限がなければサイトは更新できません。

## 動作確認

白紙の初期状態、見出し・本文追加、改行、削除、並べ替え、太字、箇条書き、リンク、プレビュー、スマートフォン幅、編集用コピーからの再編集、公開用HTMLへの出力をChromiumで確認しています。公開用HTMLは外部リソースやJavaScriptなしで表示できます。この環境の管理ポリシーにより `file://` が禁止されているため、ダブルクリック操作自体は未検証です。一般公開は実施していません。
