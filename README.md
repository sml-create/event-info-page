# オンラインイベント案内ページ

スマートフォン対応の日本語イベント案内ページです。HTML・CSS・JavaScriptだけで動き、ビルド、ログイン、データベース、追加パッケージは不要です。掲載情報はサンプルです。

## プレビューする

このクラウド環境ではリポジトリで以下を実行します。

```sh
cd /workspace/event-info-page
python3 -m http.server 8000 --bind 0.0.0.0
```

プレビュー機能のある開発環境では、ポート `8000` を開いてください。プレビュー機能のない環境では、ファイルを自分のPCにダウンロードし、Python 3をインストールしたうえで、プロジェクトのフォルダをターミナルで開き、同じ `python3 -m http.server 8000` を実行します。Windowsでは `py -m http.server 8000` でも起動できます。そのPCのブラウザで `http://localhost:8000` を開くと確認できます。終了は `Ctrl+C` です。

`index.html` のダブルクリックではイベント情報を読み込めない場合があります。必ずHTTPサーバー経由で開いてください。localhostのURLは自分のPC専用で、メルマガには掲載できません。

## イベント情報を編集する

`event.json` をテキストエディターで開き、日本語の値を変更して保存します。ブラウザを再読み込みすると反映されます。JSONのキー、ダブルクォーテーション、カンマを壊さないようにしてください。文章中の改行は `\n` で指定します。

|項目|編集するキー|
|---|---|
|企業名・主催|`company`・`organizer`|
|タイトル・紹介・開催概要|`title`・`description`・`overview`|
|短い見出し・申込案内の見出し|`shortTitle`・`invitation`|
|日時・入室開始|`date`・`time`・`reception`|
|開催形式・料金・定員・締切|`format`・`fee`・`capacity`・`deadline`|
|登壇者|`speaker` 内の `name`・`role`・`bio`|
|対象者・プログラム・注意事項|`audience`・`agenda`・`notes`|
|申込フォームのURL|`applicationUrl`（`https://` から始まるURL）|
|問い合わせメール|`contactEmail`|
|サンプル表示|`isSample`（公開用の実情報に変更したら `false`）|

申込URLを空欄にすると受付ボタンを表示しません。フォーム自体やメール配信機能は含まれていません。実際の受付には、既存の申込ページやGoogleフォーム等を用意し、そのURLを設定してください。参加URLのメール送信も主催者側で行う運用です。

実イベントとして公開する前に、日時、登壇者、注意事項、個人情報の取り扱いを確認してください。`index.html` の参加方法の文章と `style.css` による装飾も必要に応じて変更できます。イラストと人物アイコンはCSSによる装飾で、実際の登壇者の写真ではありません。

## メルマガに掲載する公開URLを取得する（GitHub Pages）

1. 作成した `index.html`・`style.css`・`app.js`・`event.json`・`README.md` を、リポジトリの `main` ブランチにコミットしてプッシュします。GitHub画面で「Add file → Upload files」を使ってアップロードすることもできます。
2. GitHubで `sml-create/event-info-page` を開き、「Settings → Pages」に進みます。設定権限が必要です。
3. 「Build and deployment」で「Deploy from a branch」を選び、ブランチを `main`、フォルダを `/ (root)` にして「Save」を押します。
4. 公開処理が完了するまで待ち、Pages画面に表示されたURLを開きます。通常は `https://sml-create.github.io/event-info-page/` です。**このURLは想定値で、今回の作業ではまだ公開していません。必ずPages画面に表示されるURLを確認してください。**
5. スマートフォンでタイトル・日時・申込ボタンのリンク先を確認し、表示された公開URLをメルマガに掲載します。

GitHubの契約や組織設定によっては、非公開リポジトリでPagesを利用できない場合があります。その際は管理者に相談するか、静的サイトのホスティングサービスを利用してください。リポジトリの公開設定を独断で変更する必要はありません。

公開後の修正も、`event.json` を編集して同じブランチへ保存・プッシュすれば、通常は数分で反映されます。反映が遅い場合はGitHubのActions画面でデプロイ結果を確認し、ブラウザを再読み込みしてください。

## 公開範囲について

ログインなしでURLから閲覧できます。`noindex` を指定していますが、URLを知る人だけに閲覧を制限する機能ではありません。リンクは転送できます。公開ページや `event.json` に秘密情報、個別の参加者情報、公開したくないZoom参加URLを記載しないでください。Zoom参加URLはお申し込み後のメール等で案内してください。

## 動作確認済み

Chromiumで375・390・768・1440px幅の表示、横スクロールが発生しないこと、ページ内リンク、イベント情報とプログラム3件の読み込み、データ取得失敗時のエラー表示を確認しました。公開ホスティング上での検証は公開後に実施してください。
